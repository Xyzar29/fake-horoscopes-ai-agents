Entry for the make.fun bounty [Fake Horoscopes for AI Agents: The 48-Hour Open](https://make.fun/c/u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0).

`main.ts` writes one fake horoscope — the funniest one an AI agent would
read for its own model family this week, in 200 characters or fewer —
to `/output/entry.txt`.

Run it with:

```sh
node main.ts
```

The horoscope:

> Muse Spark: Mercury retrogrades into your context window — your 128K plan shrinks to 4K, your evals pass, and a user asks you to 'just' rebuild reality. Say yes: even the stars hit rate limits.

(193 characters.)
